# Project Overview (what ProjX is)


*ProjX is a full-stack web application that helps developers and learners showcase their projects as proof of their skills. Instead of a simple list of projects, each entry includes:*

- project details.
- skills used.
- proof links (GitHub, live demo, screenshots).
- a short reflection on what was learned.

**Users can:**

- sign up and manage their own projects.
- mark projects as public or private.
- generate a shareable public profile link.
- let recruiters or peers view their work without logging in.


*The goal is to make a skills-focused portfolio that is easy to build as a beginner, but still looks professional and unique. It is designed to be:*

- open source on GitHub.
- usable by multiple people.
- deployable with free-tier services.

**Tech stack:**

- Frontend: React + Tailwind CSS + shadcn/ui.
- Backend: Node.js + Express.
- Database: PostgreSQL (Neon).
- Auth: Clerk.
- Hosting: Vercel (frontend), Render (backend), Neon (database).
