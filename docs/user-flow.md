# User flows (how it works)


**For a new user**

1. Visit the homepage.
2. Click “Sign up”.
3. Complete Clerk auth (email/password or OAuth).
4. Land on the dashboard.
5. See onboarding hints: “Add your first project”, “Complete your profile”.

**Adding a project**

1. From dashboard, click “Add Project”.
2. Fill in:
    - title.
    - description.
    - skills (select or type tags).
    - links (GitHub, live demo).
    - upload or paste screenshot URLs.
    - reflection text.
    - visibility (public/private).
    - featured toggle.
3. Save
4. Project appears in dashboard list.

**Sharing profile**

1. Go to profile settings or public profile preview.
2. Copy the public profile URL.
3. Share it on resume, LinkedIn, GitHub, or with recruiters.
4. Anyone with the link can view public projects and profile info.
