# Core Features (MVP + uniqueness)


**Authentication & accounts**

- Sign up / sign in via Clerk.
- User profile (name, username, bio, avatar, social links).
- Account settings (edit profile, change username, etc.).

**Projects (CRUD)**

- Create project:
    - title.
    - short description.
    - long description / case study.
    - skills used (tags).
    - GitHub repo URL.
    - live demo URL.
    - screenshots (image URLs).
    - what was learned / reflection.
    - visibility: public or private.
    - featured/pinned toggle.
- Edit project.
- Delete project.
- List projects on dashboard (with filters by skill, visibility, featured).

**Public Profile**

- Public profile page per user:
    - profile info (name, bio, avatar, social links).
    - featured project at top (if any).
    - grid or list of public projects.
    - skills overview (e.g., most used skills).
    - optional stats (number of projects, top skill).
- Shareable profile link (e.g., projx.app/u/username).

**Uniqueness features**
- Skill tags per project.
    - Reflection field (“What I learned”).
    - Featured/pinned project.
    - Public profile designed for recruiters.
    - Optional simple stats on profile.
